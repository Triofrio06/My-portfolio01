Identity // Overview

Bridging software development, payment systems, and Linux infrastructure

I am a Full-Stack Software Developer and Systems Engineer based in Nairobi, Kenya. I focus on building practical, reliable software and managing the server environments required to deploy and operate systems effectively.

My engineering work covers full-stack desktop and web applications, backend services with Node.js and Express, relational database management using Microsoft SQL Server and MySQL, and financial integrations via the M-Pesa Daraja API. I also build telecommunications services using Africa's Talking USSD API to provide mobile transaction access without requiring internet connectivity.

Alongside software development, I actively manage Linux infrastructure. Through my self-hosted environment (Frio Server), I configure and maintain Docker containers, manage self-hosted applications like Nextcloud and Gitea, establish encrypted remote access via Tailscale, and maintain production web hosting with Nginx and PM2.
